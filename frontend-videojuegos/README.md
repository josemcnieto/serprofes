# Catálogo de Videojuegos — Frontend

Práctica: **"El Cliente Impaciente"**

Este frontend ya está terminado y funcionando. Vuestro reto es construir
el backend en Express (`server.js`) para que estas peticiones dejen de fallar.

## Cómo arrancarlo

1. Descomprime este zip.
2. Abre una terminal dentro de la carpeta del proyecto.
3. Instala las dependencias:

   ```
   npm install
   ```

4. Arranca el servidor de desarrollo:

   ```
   npm run dev
   ```

5. Abre la URL que te indique la terminal (normalmente `http://localhost:5173`).

Verás la interfaz, pero mostrará un mensaje de error porque el backend
(`http://localhost:3000`) todavía no existe. ¡Ese es vuestro trabajo!
