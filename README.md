## ▶️ Cómo ejecutar los ejercicios de Node.js

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```

2. Acceder al directorio del proyecto:

```bash
cd tu-repositorio
```

3. Entrar en la carpeta del ejercicio:

```bash
cd nodejs/nombre-del-ejercicio
```

4. Ejecutar el archivo:

```bash
node app.js
```
